🎯 Brand Positioning

Schollet is a finance-first school management platform designed to help institutions:

Track income & expenses
Manage student fee collection
Maintain financial transparency
Make better financial decisions

👉 Not a full school ERP
👉 Focus = Finance clarity + simplicity

🧩 UI Design Principles

Clean spacing (no clutter)
Card-based layout
Soft shadows
Rounded corners (rounded-xl / 2xl)
Clear hierarchy (finance first)
Use basic premium animation

----------------------------------------------------------------

🧱 Component Style (shadcn aligned)

Buttons → solid primary (blue)
Tables → minimal borders
Forms → clean + labeled
Modals → centered + focused

----------------------------------------------------------------

📊 UX Philosophy

Reduce steps (especially fee collection)
Always show:
Total
Paid
Pending
Make financial data instantly readable

----------------------------------------------------------------

🧾 Voice & Tone

DO:
    Simple
    Clear
    Direct

DON'T:
    Overly technical
    Academic jargon
    Long sentences

Example:

❌ “Transaction successfully executed”
✅ “Payment recorded successfully”


----------------------------------------------------------------

🏷️ Feature Naming Style

Keep it simple and human:

“Collect Fee” (not Fee Transaction Entry)
“Add Expense”
“View Reports”
“Pending Dues”
